# 岳阳学院智慧校园数字孪生 —— 后端依赖
#
# 安装：
#     python -m pip install -r requirements.txt
#
# Python 版本：3.8 ~ 3.12 均可（本机实测 3.8.1）
#   · 后端三个文件都带 `from __future__ import annotations`，所以代码里的
#     list[dict] / dict[str, int] 这类 3.9+ 注解在运行时不会被求值；
#   · Pydantic 模型字段只用了 str / Optional[str] / List[float]，也没有 3.9+ 泛型；
#   · 下面三个包的 Requires-Python 都是 >=3.8，3.8 上装得上。
#
# 说明：后端只依赖标准库 + 下面 3 个包。
#   · 数据库用内置 sqlite3，不装 ORM（没有 SQLAlchemy）；
#   · JWT 用 hmac + hashlib 自己签，不装 python-jose / passlib；
#   · 时区、日期全用 datetime，不装 pytz；
#   · 静态文件托管（dist/）走 starlette 自带的 FileResponse，不需要 aiofiles。
# 其余传递依赖（starlette、anyio、h11、click、typing_extensions 等）由 pip 自动解析。
