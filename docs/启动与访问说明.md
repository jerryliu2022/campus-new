# 岳阳学院智慧校园数字孪生 —— 启动与访问说明

> 项目根目录：`E:\practice-examples\competition\campus-new`
> 本文档中的命令都**必须在项目根目录下执行**，且后端与前端需要**各开一个终端窗口同时运行**。

---

## 0. 一句话架构

```
浏览器
  │
  ├─ http://localhost:4175/        主页（3D 数字孪生，需登录）
  ├─ http://localhost:4175/rag     独立 RAG 问答页（免登录）
  └─ http://localhost:4175/learn   学习中心（免登录）
        │
        │  Vite 开发服务器 :4175
        │  把所有 /api/** 请求反向代理到 ↓
        │
        └─ FastAPI 后端 :8000
              ├─ /api/*       3D 首页业务接口（登录 / 查询 / 房间 / 通知 / 锚点）
              ├─ /api/rag/*   RAG 问答接口（无鉴权）
              └─ /api/learn/* 学习中心教学接口（无鉴权，跑独立测试库）
```

**关键点：浏览器只需要访问 4175，不需要知道 8000。** 前端所有 `/api/xxx` 都由 Vite 代理转发（配置见 `vite.config.js`），因此不存在跨域问题。

## 2. 启动后端（:8000）

打开一个终端：

```powershell
cd /d E:\practice-examples\competition\campus-new
"E:\program file\python\python38\python.exe" -m uvicorn backend.main:app --host 0.0.0.0 --port 8000
```

**启动成功的标志**（终端出现这几行即可，不要关窗口）：

```
INFO:     Uvicorn running on http://0.0.0.0:8000 (Press CTRL+C to quit)
INFO:     Application startup complete.
```

**验证后端是否活着**：浏览器打开 <http://127.0.0.1:8000/api/health>，应返回：

```json
{"status":"ok","time":1789454486,"buildings":21,"room_anchors":630,"road_nodes":48,"road_edges":56}
```

几点说明：

- `--host 0.0.0.0` 是刻意加的，这样同局域网的其他机器也能访问；
- `backend/main.py` 启动时会调用 `init_db()` **幂等重建** `data/campus.db` 的基础数据（用户、通知、房间锚点覆盖等），这是正常行为，不是数据丢失；
- 后端进程**不需要重启**就能看到 `/api/rag/*` 和 `/api/learn/*` 的效果；但如果你改了 `backend/*.py`，uvicorn 没开 `--reload`，需要手动 `Ctrl+C` 再重新执行上面的命令。

## 3. 启动前端（:4175）

**再开一个终端**（后端那个不要关）：

```powershell
cd /d E:\practice-examples\competition\campus-new
npx vite --host 0.0.0.0 --port 4175
```

**启动成功的标志**：

```
  VITE v6.4.3  ready in 1234 ms
  ➜  Local:   http://localhost:4175/
  ➜  Network: http://192.168.x.x:4175/
```

> ⚠️ **不要用 `npm run dev`**。`package.json` 里的 `dev` 脚本是 `vite --host 0.0.0.0`，**没有指定端口**，Vite 会默认跑在 **5173**。
> 本机 5173 已经被另一个项目（`campus-sandbox-origin`）占用，会冲突或串页。
> 固定用 `npx vite --host 0.0.0.0 --port 4175`。

依赖没装的情况下先跑一次：

```powershell
cd /d E:\practice-examples\competition\campus-new
npm install
```

| 页面 | 地址 | 是否登录 | 内容 |

### 主页演示账号

| 角色 | 账号 | 密码 |
|---|---|---|
| 学生 | `student` | `campus123` |
| 辅导员 | `counselor` | `campus123` |
| 管理员 | `admin` | `admin123` |

### 路由是怎么分流的

`src/main.jsx` 里的 `Root()` 直接读 `window.location.pathname`，没有用路由库：

- `/rag` → 渲染 `RagPage`（懒加载）
- `/learn` → 渲染 `LearnPage`（懒加载）
- 其它任何路径 → 渲染 `App`（也就是 3D 主页）

所以 `/learn`、`/rag` 是**独立入口**，打开就是全屏页面，不经过登录、也不加载 3D 场景。

## 5. 局域网 / 手机访问

前后端都监听了 `0.0.0.0`，同一 WiFi 下的其他设备可以直接访问：

```
http://192.168.31.41:4175/        主页
http://192.168.31.41:4175/rag     RAG 问答页
http://192.168.31.41:4175/learn   学习中心
```

把 `192.168.31.41` 换成你本机当前的 IPv4 地址即可（`ipconfig` 查看）。
因为接口走的是 Vite 服务端代理，跨机访问同样不会踩跨域。

> 注意：`backend/main.py` 的 CORS 白名单只放了 `http://localhost:4175` 和 `http://127.0.0.1:4175`。
> 走 4175 代理没事；但如果有人**直连** `http://192.168.31.41:8000/api/...`，浏览器会拦截。

## 6. 停止服务

前端和后端分别在各自的终端里按 `Ctrl+C` 即可。

如果终端已经关掉、进程还在后台跑，按端口找进程再杀掉：

```powershell
netstat -ano | findstr :4175
taskkill /PID <上一步查到的PID> /F

netstat -ano | findstr :8000
taskkill /PID <上一步查到的PID> /F
```

> ⚠️ **不要动 5173 端口上的进程**，那是另一个独立项目 `campus-sandbox-origin`，和本项目无关。

## 7. 常见问题

| 现象 | 原因与处理 |
|---|---|
| 后端启动报 `ModuleNotFoundError: No module named 'fastapi'` | 用了 PATH 里的 `python`（3.13）。改用绝对路径 `"E:\program file\python\python38\python.exe" -m uvicorn ...` |
| 后端报 `[Errno 10048] address already in use` | 8000 被占。先 `netstat -ano \| findstr :8000` 找到并杀掉旧进程 |
| 页面白屏 / 卡在「正在加载学习中心…」 | 前端起来了但后端没起，或后端挂了。先确认 <http://127.0.0.1:8000/api/health> 能出 JSON |
| 前端起在了 5173 而不是 4175 | 用了 `npm run dev`。改用 `npx vite --host 0.0.0.0 --port 4175` |
| 主页登录提示「账号或密码错误」 | 按上表核对演示账号；账号数据由 `init_db()` 播种在 `data/campus.db` |
| RAG 问答答案像是在背数据 | 这是设计如此：RAG 走的是「意图解析 → 确定性工具检索 → 模板生成」，**不调用大模型**，答案是算出来的、可溯源 |

## 8. 生产模式（可选：只用 8000 一个端口）

不想要两个终端时，可以先把前端打包，再由 FastAPI 直接托管静态文件：

```powershell
cd /d E:\practice-examples\competition\campus-new
npm run build          # 产出 dist/
```

`backend/main.py` 末尾会检测 `dist/` 是否存在，**存在就自动挂载 SPA 路由**。之后只启动后端，直接访问：

```
http://127.0.0.1:8000/        主页
http://127.0.0.1:8000/rag     RAG 问答页
http://127.0.0.1:8000/learn   学习中心
http://127.0.0.1:8000/docs    FastAPI 自动生成的接口文档
```

> ⚠️ 生产模式读的是 `dist/` 里**上次构建的旧代码**。开发/调试阶段请老老实实用 4175 的 Vite 开发服务器（改代码即时热更新）；只有确认要演示最终效果时再 `npm run build` 重新打包。

## 9. 附：核心接口速查

| 接口 | 方法 | 说明 |
|---|---|---|
| `/api/health` | GET | 后端健康检查 |
| `/api/login` | POST | 登录，body `{"username","password"}`，返回 JWT |
| `/api/query` | POST | 3D 主页的时空问答，body `{"query","origin"}` |
| `/api/rag/ask` | POST | RAG 问答，body **`{"question":"..."}`**（字段名是 `question`，不是 `query`） |
| `/api/rag/eval` | GET | 内置评测集回归（当前 12/12 通过） |
| `/api/rag/data/{kind}` | GET | 读取源数据，kind ∈ students / schedule / timetable / training_plan / validation |
| `/api/learn/health` | GET | 教学测试库状态 |
| `/api/learn/sql` | POST | 在教学库 `data/learn_test.db` 执行单条 SQL |
| `/api/learn/demo/chain` | GET | 全链路演示：前端 → 后端 → SQLite → JSON |
| `/api/learn/reset` | POST | 重置教学测试库 |
